1. 构建 family manifest
对应脚本：

build_geo_current_family_manifest.py
最基本用法：

python scripts/build_geo_current_family_manifest.py `
  --dataset-root "你的数据集根目录" `
  --output-manifest "你的输出目录\family_manifest.jsonl" `
  --splits train val `
  --tile-size-px 1024 `
  --overlap-px 256 `
  --keep-margin-px 128 `
  --review-crop-pad-px 64 `
  --tile-min-mask-ratio 0.02 `
  --tile-min-mask-pixels 256 `
  --search-within-review-bbox `
  --fallback-to-all-if-empty
如果你要做分片处理，还可以加：

  --shard-index 0 `
  --num-shards 4
2. 一次性导出 A/B 两阶段数据集
对应脚本：
export_llamafactory_both_from_geo_current_family_manifest.py
用法：

python scripts/export_llamafactory_both_from_geo_current_family_manifest.py `
  --family-manifest "你的输出目录\family_manifest.jsonl" `
  --output-root "你的处理结果输出目录" `
  --splits train val `
  --use-system-prompt `
  --resample-step-px 12.0 `
  --boundary-tol-px 2.5 `
  --trace-points 8 `
  --state-mixture-mode mixed `
  --state-no-state-ratio 0.30 `
  --state-weak-ratio 0.40 `
  --state-full-ratio 0.30 `
  --state-weak-trace-points 3 `
  --state-line-dropout 0.40 `
  --state-point-jitter-px 2.0 `
  --state-truncate-prob 0.30
这一步跑完后，你会得到：

stage_a/dataset
stage_b/dataset
3. 合并多台机器处理好的结果
对应脚本：

merge_geo_current_v1_processed_shards.py
Windows 下直接这样：

python scripts/merge_geo_current_v1_processed_shards.py `
  --output-root "合并输出目录" `
  --shard-roots "分片目录1" "分片目录2" "分片目录3"


  可以，已经给你补了 Python 脚本：

run_geo_current_v1_process_val_dataset.py
它的作用是：

只处理 val
只构建 family_manifest
支持分片
不导出 stage_a/stage_b 监督数据
Windows PowerShell 启动命令
直接这样跑：

python scripts/run_geo_current_v1_process_val_dataset.py `
  --dataset-root "你的数据集根目录" `
  --output-manifest "D:\output\family_manifest_val.jsonl" `
  --tile-size-px 1024 `
  --overlap-px 256 `
  --keep-margin-px 128 `
  --review-crop-pad-px 64 `
  --tile-min-mask-ratio 0.02 `
  --tile-min-mask-pixels 256 `
  --search-within-review-bbox `
  --fallback-to-all-if-empty
如果你要分片处理验证集

python scripts/run_geo_current_v1_process_val_dataset.py `
  --dataset-root "你的数据集根目录" `
