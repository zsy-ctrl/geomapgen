# 当前数据集处理与验证启动说明

这份说明对应当前 `geo_current` 数据集处理链。

当前新增了一条 **一键制作脚本**：

- [build_geo_current_manifest_and_datasets.py](c:/DevelopProject/VScode/geomapgen/scripts/build_geo_current_manifest_and_datasets.py)

它会一次完成：

1. 构建 `family_manifest.jsonl`
2. 导出 `stage_a/dataset`
3. 导出 `stage_b/dataset`
4. 基于 `stage_a/dataset` 再构建一份 `fixed16` target-box 数据集
5. 基于 `stage_b/dataset` 再构建一份 `fixed16` target-box 数据集

并且支持你**手动分别指定训练集和验证集原始路径**。

## 1. 一键制作 manifest + train/val 数据集

最常用命令如下：

```powershell
python scripts/build_geo_current_manifest_and_datasets.py `
  --train-root "D:\your_raw_dataset\train" `
  --val-root "D:\your_raw_dataset\val" `
  --output-root "D:\output\processed_all" `
  --splits train val `
  --image-relpath "patch_tif/0.tif" `
  --mask-relpath "patch_tif/0_edit_poly.tif" `
  --lane-relpath "label_check_crop/Lane.geojson" `
  --intersection-relpath "label_check_crop/Intersection.geojson" `
  --tile-size-px 896 `
  --overlap-px 232 `
  --keep-margin-px 116 `
  --review-crop-pad-px 64 `
  --tile-min-mask-ratio 0.02 `
  --tile-min-mask-pixels 256 `
  --search-within-review-bbox `
  --fallback-to-all-if-empty `
  --resample-step-px 4.0 `
  --boundary-tol-px 2.5 `
  --trace-points 8 `
  --state-mixture-mode full `
  --state-no-state-ratio 0.30 `
  --state-weak-ratio 0.40 `
  --state-full-ratio 0.30 `
  --state-weak-trace-points 3 `
  --state-line-dropout 0.40 `
  --state-point-jitter-px 2.0 `
  --state-truncate-prob 0.30 `
  --empty-patch-drop-ratio 0.95 `
  --empty-patch-seed 42 `
  --fixed16-output-name "fixed16_stage_a" `
  --fixed16-stageb-output-name "fixed16_stage_b" `
  --fixed16-grid-size 4 `
  --fixed16-target-empty-ratio 0.10 `
  --fixed16-seed 42 `
  --fixed16-resample-step-px 4.0 `
  --fixed16-boundary-tol-px 2.5 `
  --fixed16-image-root-mode symlink `
  --use-system-prompt
```

输出目录结构：

- `D:\output\processed_all\family_manifest.jsonl`
- `D:\output\processed_all\stage_a\dataset`
- `D:\output\processed_all\stage_b\dataset`
- `D:\output\processed_all\fixed16_stage_a`
- `D:\output\processed_all\fixed16_stage_b`
- `D:\output\processed_all\build_manifest_and_datasets.summary.json`

这里会同时保留四份主要数据：

- **训练一阶段母集**：`stage_a/dataset`
- **训练二阶段母集**：`stage_b/dataset`
- **训练一阶段 fixed16**：`fixed16_stage_a`
- **训练二阶段 fixed16**：`fixed16_stage_b`

## 2. 空 patch 丢弃规则

当前除了原本的 `mask` 相关 patch 选择逻辑外，还新增了：

- **对内部不包含任何道路/路口几何的空 patch，下采样丢弃 95%**

规则位置：

- [export_llamafactory_both_from_geo_current_family_manifest.py](c:/DevelopProject/VScode/geomapgen/scripts/export_llamafactory_both_from_geo_current_family_manifest.py)

说明：

- 这一步发生在 **导出 Stage A / Stage B 数据集时**
- `family_manifest` 本身仍然完整保留
- `stage_a` 和 `stage_b` 会使用**同一批被保留的 patch**

可调参数：

- `--empty-patch-drop-ratio 0.95`
- `--empty-patch-seed 42`

如果你想不丢空 patch，可以改成：

```powershell
--empty-patch-drop-ratio 0
```

## 3. 如果你还想手动分步执行

### 3.1 只构建 manifest

```powershell
python scripts/build_geo_current_family_manifest.py `
  --train-root "D:\your_raw_dataset\train" `
  --val-root "D:\your_raw_dataset\val" `
  --output-manifest "D:\output\family_manifest.jsonl" `
  --splits train val `
  --image-relpath "patch_tif/0.tif" `
  --mask-relpath "patch_tif/0_edit_poly.tif" `
  --lane-relpath "label_check_crop/Lane.geojson" `
  --intersection-relpath "label_check_crop/Intersection.geojson" `
  --tile-size-px 896 `
  --overlap-px 232 `
  --keep-margin-px 116 `
  --review-crop-pad-px 64 `
  --tile-min-mask-ratio 0.02 `
  --tile-min-mask-pixels 256 `
  --search-within-review-bbox `
  --fallback-to-all-if-empty
```

### 3.2 从 manifest 导出 Stage A / Stage B

```powershell
python scripts/export_llamafactory_both_from_geo_current_family_manifest.py `
  --family-manifest "D:\output\family_manifest.jsonl" `
  --output-root "D:\output\processed" `
  --splits train val `
  --resample-step-px 4.0 `
  --boundary-tol-px 2.5 `
  --trace-points 8 `
  --state-mixture-mode full `
  --state-no-state-ratio 0.30 `
  --state-weak-ratio 0.40 `
  --state-full-ratio 0.30 `
  --state-weak-trace-points 3 `
  --state-line-dropout 0.40 `
  --state-point-jitter-px 2.0 `
  --state-truncate-prob 0.30 `
  --empty-patch-drop-ratio 0.95 `
  --empty-patch-seed 42 `
  --use-system-prompt
```

### 3.3 基于 Stage A 再构建 fixed16 数据集

```powershell
python scripts/build_patch_only_fixed_grid_targetbox_dataset.py `
  --input-root "D:\output\processed\stage_a\dataset" `
  --output-root "D:\output\processed\fixed16_stage_a" `
  --splits train val `
  --grid-size 4 `
  --target-empty-ratio 0.10 `
  --seed 42 `
  --resample-step-px 4.0 `
  --boundary-tol-px 2.5 `
  --use-system-prompt-from-source `
  --image-root-mode symlink
```

说明：

- 这一份是 **训练一阶段的 fixed16 target-box 数据集**
- 原始 `stage_a/dataset` 会完整保留，不会被覆盖

### 3.4 基于 Stage B 再构建 fixed16 数据集

```powershell
python scripts/build_patch_only_fixed_grid_targetbox_dataset.py `
  --input-root "D:\output\processed\stage_b\dataset" `
  --output-root "D:\output\processed\fixed16_stage_b" `
  --splits train val `
  --grid-size 4 `
  --target-empty-ratio 0.10 `
  --seed 42 `
  --resample-step-px 4.0 `
  --boundary-tol-px 2.5 `
  --use-system-prompt-from-source `
  --image-root-mode symlink
```

说明：

- 这一份是 **训练二阶段的 fixed16 target-box 数据集**
- 脚本会保留 `stage_b` 源数据里的 `state_lines`
- 原始 `stage_b/dataset` 会完整保留，不会被覆盖

## 6. 当前最常调的参数

- `--tile-size-px`
- `--overlap-px`
- `--keep-margin-px`
- `--review-crop-pad-px`
- `--tile-min-mask-ratio`
- `--tile-min-mask-pixels`
- `--resample-step-px`
- `--boundary-tol-px`
- `--empty-patch-drop-ratio`
- `--fixed16-target-empty-ratio`
- `--fixed16-grid-size`
- `--fixed16-output-name`
- `--fixed16-stageb-output-name`

如果你现在的重点是减少“审核区域内部的大块纯空白样本”，最先调的就是：

- `--empty-patch-drop-ratio`
- `--fixed16-target-empty-ratio`

默认：

```powershell
--empty-patch-drop-ratio 0.95
```

而 fixed16 这条链默认会把 box 级 empty ratio 控制到：

```powershell
--fixed16-target-empty-ratio 0.10
```
