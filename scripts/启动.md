# 当前数据集制作与验证启动说明

这份说明对应当前 `geo_current_v1` 的**滑动窗口裁剪版本**。

当前主逻辑是：

- patch 由滑动窗口生成，不再使用中心点 family grid
- 图像先在整张原始 tif 上应用 `review mask`，mask 外像素直接置黑
- 线与路口几何先在全局坐标下处理，再按 patch 裁切
- `keep_box` 不再是简单四边统一缩 `keep_margin`，而是按**相邻窗口中线归属**计算
  - 内部 patch：按相邻 patch 中线分配
  - 最外层 patch：保留到外边界，不再额外吃掉一圈

## 3. 当前关键参数

### patch 参数

- `tile_size_px = 896`
- `overlap_px = 232`
- `keep_margin_px = 116`

说明：

- stride = `896 - 232 = 664`
- 内部 patch 的归属边界按相邻 patch 中线计算
- 最外层 patch 的 `keep_box` 会保留到外边界

### mask 与搜索区域

- `mask_threshold = 127`
- `review_crop_pad_px = 64`
- `search_within_review_bbox = true`

### 几何参数

- `resample_step_px = 4.0`
- `boundary_tol_px = 2.5`
- `trace_points = 8`

### 当前几何处理逻辑

- lane：
  - 先做全局 `review mask` 裁切
  - 再按 patch `keep_box` 裁切
  - 不再做额外的“拉直简化”
  - 再按 `resample_step_px = 4.0` 重采样
  - 如果 lane 穿进 intersection polygon，会先把 polygon 内部的 lane 段切掉
  - 保留下来的 lane 端点再用小阈值吸附到 polygon 边界
- intersection：
  - 保留为 `intersection_polygon`
  - patch 内按 polygon ring 裁切
  - ring 保证闭合，首尾点一致

- `scripts/reconstruct_geo_current_from_processed_dataset.py`

- 导出 `Lane.geojson` 与 `Intersection.geojson`
- 额外输出 3 张可视化图：

  - `masked_reconstructed_overlay_float.png`
    - 取整前的浮点监督线

- 回拼 GeoTIFF 来自**已裁剪后的 patch 图像**
- 导出的 `Lane.geojson` / `Intersection.geojson` 现在优先使用 `target_lines_float`

## 5. 如果要重新看效果，必须重跑哪些步骤

下面这些改动不会自动作用到旧数据：

- `keep_box` 外边界修正
- lane 端点吸附到 polygon 边界
- lane 不再额外拉直
- `resample_step_px = 4.0`
- 验证导出优先使用浮点线

所以要看最新结果，至少需要重跑：

1. `build_geo_current_family_manifest.py`
2. `export_llamafactory_both_from_geo_current_family_manifest.py`
3. `reconstruct_geo_current_from_processed_dataset.py`

## 6. Overlay 端点序号说明

验证脚本现在会在 overlay 中额外标出端点序号：

- `start1 / start2 / ...`
- `cut1 / cut2 / ...`
- `end1 / end2 / ...`

排序规则是：

- 以**当前 patch 的局部坐标原点 `(0, 0)`** 为基准
- 在同一个 patch 内，分别对 `start`、`cut`、`end` 三类端点独立排序
- 距离 patch 原点最近的叫 `start1` / `cut1` / `end1`
- 第二近的叫 `start2` / `cut2` / `end2`

注意：

- 这个编号只用于验证可视化，方便人工检查 patch 内端点顺序
- 不会改动训练数据本身

## 7. 当前真值转换口径

- `mask` 只用于：
  - 图像内容遮挡
  - patch 搜索范围
  - patch 可视化
- `mask` **不再用于裁断训练真值几何**
  - `lane` 不再经过 `mask_clip_line(...)`
  - `intersection_polygon` 也不按 mask 去切

- 当前真值允许的几何改动只有：
  - `resample-step-px`

- 当前重采样规则：
  - 按固定步长采样
  - 最后一段如果长度不足一个完整步长，就保留剩余长度
  - 不再为了“均匀分布”把整条线重新平均摊开

- `resample-step-px = 4.0` 的真实长度换算：
  - 如果原始 tif 分辨率是 `r` 米/像素
  - 那么真实步长就是 `4.0 * r` 米

- 当前训练数据中的：
  - `target_lines`
  - `state_lines`
  都改成了浮点 patch-local UV 坐标
  - `u = x / patch_width`
  - `v = y / patch_height`
  - 取值范围都是 `[0, 1]`

- 量化后的整数坐标只保留给验证可视化对照：
  - `target_lines_quantized`

- 当前验证和可视化：
  - 先从 UV 转回 patch-local 像素坐标
  - 再投影到整图 / GeoJSON
